# Definition of done

**Valmis ominaisuus täyttää kaikki seuraavat ehdot:**


- Toteutus vastaa hyväksyttyjä vaatimuksia ja hyväksymiskriteerejä.
- Koodi on GitHubissa, katselmoitu ja yhdistetty **main**-haaraan.
- Koodi on ajettu lintterin läpi.
- Tarvittavat testit menevät läpi.
- Ominaisuus toimii oikean palvelimen ja tietokannan kanssa.
- Ominaisuus on julkaistu Azureen ja testattu julkaistusta osoitteesta.
- Koko tiimi osaa esitellä ja selittää toteutuksen.
- Tarvittava dokumentaatio on päivitetty.
